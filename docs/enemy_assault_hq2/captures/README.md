# Assault Meshy rifle captures

These PNGs were regenerated on 3 November 2026 with Blender 4.3.2 / CPU Cycles from the final optimized runtime GLB. The capture script applies Blender IK to the two authored Meshy hand anchors and renders LOD0.

- `capture_meshy_weapon_grip_front.png`: front three-quarter view of the Assault holding its detached Meshy rifle.
- `capture_meshy_weapon_grip_side.png`: alternate side three-quarter view of the same ready pose.

They show the actual runtime model, materials, prop and rigged body. They are static rig/hand-fit captures, not animation frames, a Godot gameplay view or an iPhone screenshot. Hand anchors and locomotion are validated separately by the Godot tests described in `../rigging_report.md`.
