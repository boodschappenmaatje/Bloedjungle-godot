# Arcade VFX render captures

These are actual captures from `scenes/tests/arcade_vfx_lab.tscn`, rendered with Godot 4.6.3 using Mesa llvmpipe's OpenGL Compatibility renderer at 1280×720. The final image checks the same lab at a 934×430 landscape viewport.

The scene uses the game's existing player, M1911, camera, level, projectile collision path, and FX code. Captures pause the game at the shot or hit frame so short-lived effects can be reviewed in a slow software-rendering environment.

The 934×430 image is a viewport layout check only. It is not an iPhone/Xogot device capture or a performance measurement.
