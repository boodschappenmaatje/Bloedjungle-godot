# Loopgraaf (Blender-bron)

`assets/loopgraaf.glb` komt uit `maak_loopgraaf.py` (`pip install bpy`):

    python3 maak_loopgraaf.py uit/
    python3 render.py uit/loopgraaf.blend $PWD/p.png 4.5,-5,3.6 40

Put van 4,8 x 1,4 m en 0,95 m diep met plankenwanden, looprooster, ladder, aarden rand en zandzakken. De game snijdt een gat in de grond (shader `pits`).
