# MotionBricks fase-1 preview

Open `motionbricks_soldier_preview.tscn` in Godot 4.7.2 om één bestaand
junglecommando met zijn eigen rig te bekijken. De scene verwijst rechtstreeks
naar `assets/soldaat_jungle_commando.glb`; er staat geen kopie van het model in
deze map.

Toetsen: `1` = stil, `2` = lopen, `3` = rennen. Deze drie clips zijn de al
bestaande Godot-animaties. De scene is een geïsoleerde retarget-doelpreview en
speelt nog geen MotionBricks-output af. Zie
`docs/motionbricks/MOTIONBRICKS_INTEGRATION_1_0_REPORT.md` voor de reden en
voor de gemeten upstream-proef.
