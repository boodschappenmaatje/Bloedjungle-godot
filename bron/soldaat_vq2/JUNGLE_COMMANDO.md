# Jungle Commando Tiger Stripe — High Quality Showcase v1.0

This is the player-only appearance approved in GitHub issue #138. It is an original
modern jungle commando look and does not copy a film character. The default player
variant has short dark hair, light stubble, a long-sleeved Tiger Stripe uniform,
compact olive vest, three magazine pouches, radio, IFAK, belt and boots. It has no
headband or helmet. Existing player tops remain selectable; allies and enemies keep
using the shared `soldaat_vq2.glb` unchanged.

The hands are covered by dark gloves; the scalp is assigned a short dark-brown PBR
hair surface; combat boots use a subdued dark material while keeping their existing
panel and lace detail. The radio is kept below the collar line. The game default
carries the existing M1911 through its normal `DEF-handR` attachment; that weapon
mesh is included in the review USDZ only, not duplicated in the player GLB.

## Production files

- Editable Blender 4.5.15 source: `Bloedjungle_Jungle_Commando_HQ.blend`
- Godot player-only runtime model: `assets/soldaat_jungle_commando.glb`
- Tiger Stripe 2K albedo: `jungle_commando/tiger_stripe_albedo_2048.png`
- Rebuild script: `maak_jungle_commando.py`
- Focused USDZ preparation: `maak_jungle_commando_iphone_preview.py`
- Showcase renders: generated by `render_jungle_commando.py`
- GLB rig/PBR/UV/triangle receipt: `jungle_commando/validation.json`

The generator reads `assets/soldaat_vq2.glb` and writes separate outputs; it never
changes the shared VQ2 model. It keeps the original skin, uniform normal and ORM
(occlusion/roughness/metallic) maps. The new Tiger Stripe base color is generated as
a UV texture. New olive nylon/webbing, short hair and parkerized steel have 512px
base-color/normal/roughness maps. Boots retain the source equipment normal/ORM maps.
The active game look is 15,552 triangles at the character's 1.6m scale; the player
GLB also holds the alternative tops, so its combined mesh total is larger. No outside
textures or downloads are used.

The new variant shares the same 53-bone DEF rig and the ten clips embedded in the
VQ2 GLB. The existing `scripts/soldier_model.gd` still merges the other seven clips
(`klimmen`, `zitten`, `rollen`, `sprinten`, `explosie_dood`, `brand_rennen`,
`brand_val`) from their existing resources. Weapon attachment, pose, recoil,
hit/death, ragdoll, input, collision and player-control code are unchanged.

## Rebuild on the production iMac

```sh
BLENDER="/Applications/Blender.app/Contents/MacOS/Blender"
"$BLENDER" --background --factory-startup \
  --python bron/soldaat_vq2/maak_jungle_commando.py -- \
  --source assets/soldaat_vq2.glb \
  --blend /path/to/output/Bloedjungle_Jungle_Commando_HQ.blend \
  --glb /path/to/output/soldaat_jungle_commando.glb \
  --textures /path/to/output/textures \
  --report /path/to/output/build.json
```

The generator refuses to overwrite output files. Keep the Blender source, runtime
GLB and maps as separate deliverables. The GLB retains player top variants, but
omits enemy/ally meshes because the game continues to use the shared VQ2 asset for
those roles.
