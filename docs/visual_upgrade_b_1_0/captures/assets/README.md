# Blender asset close-ups

These three images are Eevee renders of the authored Blender source mesh at LOD0,
made only to inspect plant silhouettes and PBR response. They are not Godot
gameplay screenshots and are not used as proof of the in-game visual result. The
game-camera captures and their comparison against approved B are in the sibling
`../after/` and `../compare/` folders.
